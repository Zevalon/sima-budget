# SIMA Phase 1A — Fix 02

## Symptom

`make phase1a-check` reaches frontend Prettier and reports generated files:

```text
dist/assets/*.js
dist/assets/*.css
dist/index.html
```

## Cause

`dist/` is generated by `vite build` but was not excluded from
`prettier --check .`.

Generated build artifacts should never be reformatted or maintained manually.

## Fix

Adds `apps/frontend/.prettierignore` with exclusions for:

- `node_modules/`
- `dist/`
- `coverage/`
- `playwright-report/`
- `test-results/`
- `.vite/`

## Apply

Extract over the repository root:

```bash
unzip -o SIMA_Phase1A_Fix02.zip -d ~/projects/sima-budget
```

Then rerun:

```bash
cd ~/projects/sima-budget
make phase1a-check
```

No database reset, migration rollback, dependency reinstall, or deletion of
`dist/` is required.
