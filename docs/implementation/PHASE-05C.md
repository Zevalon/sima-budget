# Phase 5C - CSV / Excel / PDF Export

## Objective

Export the same canonical reporting model used by the Reports UI without duplicating financial formulas.

## Endpoint

```text
GET /api/v1/reports/financial-summary/export
```

Query parameters:

- `fiscal_year_id` - required;
- `format` - `csv`, `xlsx`, or `pdf`;
- `organization_unit_id` - optional and validated against `reports.view` scope;
- `month` - optional, 1-12, limits the monthly breakdown only;
- `budget_category_id` - optional, limits the category breakdown only.

## Export formats

### CSV

UTF-8 with BOM. Contains summary, unit, monthly realization, and category sections.

### Excel (.xlsx)

Dependency-free OOXML workbook generated by the backend using the Python standard library.

Sheets:

1. Ringkasan
2. Unit
3. Bulanan
4. Kategori

### PDF

Dependency-free text report generated as a standards-compatible PDF. It contains the canonical summary and the same scoped breakdowns.

## Security

Exports use the same `reports.view` permission and organization-unit scope evaluation as the JSON report endpoint.

A direct attempt to export another unit outside the user's scope returns `403 Forbidden`.

## Financial semantics

Export code receives an already-calculated `FinancialSummaryResponse`; it does not recalculate Allocated, Committed, Realized, Available, Remaining, or Utilization.

Month/category filters affect only their corresponding breakdown sections. Fiscal-year summary totals remain cumulative.

## Database

No database migration is required.
